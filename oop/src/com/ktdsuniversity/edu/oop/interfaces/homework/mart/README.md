식자재 마트 애플리케이션.

우리 동네 식자재 마트에는 아래 상품을 판매합니다.

1. 일반 상품 (상품의 이름, 가격)

2. 신선 상품 (상품의 이름, 가격, 유통기한, 보관온도)

3. 냉동 상품 (상품의 이름, 가격, 유통기한, 보관온도)

4. 주류 (상품의 이름, 가격, 보관온도, 구매제한나이, 알코올 함량)

식자재 마트에서는 상품들을 진열해서 판매합니다,

고객들은 두 가지 그룹으로 나뉩니다.

1. 일반 손님 (이름, 보유 현금, 구매한 상품 목록)

2. 신규 손님 (이름, 보유 현금, 구매한 상품 목록)

3. 단골 손님 (이름, 보유 현금, 구매한 상품 목록)

일반손님이 제품을 구매할 경우 상품들의 가격을 그대로 받습니다.

신규손님이 제품을 구매할 경우 최종 결제 금액의 10%를 할인 받습니다.

단골손님이 제품을 구매할 경우 가장 저렴한 상품의 금액을 받지 않습니다.

상품들(일반상품, 신선상품, 냉동상품, 주류)

고객들(일반 손님, 신규 손님, 단골 손님)

상속과 인터페이스를 이용해 완성합니다.
