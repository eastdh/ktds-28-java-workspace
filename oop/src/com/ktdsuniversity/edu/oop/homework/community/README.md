# 게시글과 댓글을 관리하는 애플리케이션을 Scanner, 인터페이스, List를 이용해 만들어보세요.

 

## 게시판 작성을 위한 데이터 명세
1. 게시판의 게시글 정보
    - 게시글 번호 (리스트의 인덱스 번호)
    - 게시글 제목
    - 게시글 작성자 (직접 입력)
    - 게시글 작성 날짜 (직접 입력)
    - 게시글 조회 수
    - 게시글의 내용
    - 게시글의 댓글 목록

2. 게시글의 댓글 정보 (게시글 has a 댓글 목록)
    - 댓글 번호 (리스트의 인덱스 번호)
    - 댓글 내용 (직접 입력)
    - 댓글 작성자의 이름 (직접 입력)
    - 댓글 작성 날짜 (직접 입력)
    - 댓글 추천 수

 

게시판의 기능
기능은 이름과 파라미터로 작성해 두었으니, 코드 작성시 참고하세요.

1. 게시글 작성하기()
    - 게시글 번호는 자동으로 생성되어야 합니다.
    - 게시글 제목은 필수로 입력해야 하며, 30글자 내로 작성해야 합니다. (공백만 작성할 경우 0글자로 처리합니다.)
    - 게시글 제목을 입력하지 않았거나, 길이가 초과 한다면, ArticleException 예외가 던져져야 합니다.
    - 게시글 작성자 이름은 필수 입력 값이며 길이의 제한은 없습니다.
    - 게시글 작성자의 이름을 입력하지 않았다면, ArticleWriterException 예외가 던져져야 합니다.
    - 게시글 조회 수는 항상 0으로 시작해야 합니다.
    - 게시글의 댓글은 10개까지만 작성할 수 있습니다.
    - 게시글 등록이 완료되었다면 "게시글 작성이 완료되었습니다."를 출력합니다.

 

2. 모든 게시글 출력하기()
    - 게시글 목록을 출력할 때, 아래와 같이 출력되어야 합니다.
    - 게시글 번호. 게시글 제목 (댓글의 수)
      
      ```text
      예>
      1. 게시글 입니다. (0)
      2. 게시글 입니다2. (3)
      - 존재하는 게시글이 없을 경우 "아직 등록된 게시글이 없습니다."를 출력합니다.
      ```
 

3. 게시글 번호로 게시글 정보 출력하기(출력하려는 게시글 번호)
    - 게시글의 정보를 출력하면 해당 게시글의 조회수가 1증가해야 합니다.
    - 게시글의 정보를 출력할 때, 해당 게시글의 모든 정보가 출력되어야 하며, 가장 아래에는 댓글의 목록이 출력되어야 합니다.
    - 만약, 존재하지 않는 게시글의 번호일 경우 "잘못된 게시글 번호입니다"가 출력되어야 합니다.
    - 만약, 댓글이 하나도 없을 때, 게시글 정보 아래에 "등록된 댓글이 없습니다." 로 출력합니다.

 

4. 게시글 수정하기(수정하려는 게시글 번호)
    - 게시글의 번호를 이용해 정보를 수정할 수 있습니다.
    - 만약, 존재하지 않는 게시글을 수정하려 할 경우 "잘못된 게시글 번호입니다"가 출력되어야 합니다.
    - 수정 가능한 게시글의 정보는 아래와 같습니다. (아래 정보를 제외한 나머지 정보는 수정할 수 없습니다)
    - 1. 게시글의 제목
    - 2. 게시글의 내용

 

5. 게시글 번호로 게시글 삭제하기(삭제하려는 게시글 번호)
    - 게시글의 번호를 이용해 게시글 목록에서 해당 게시글을 삭제합니다.
    - 만약, 존재하지 않는 게시글을 삭제하려 할 경우 "잘못된 게시글 번호입니다"가 출력되어야 합니다.

 

6. 게시판에 등록된 게시글의 개수 출력하기()
    - 게시판에 등록된 게시글이 몇 개인지 세어 출력합니다.
    - 출력형태는 아래와 같습니다.
    - n개의 게시글이 등록되었습니다.
    - 만약, 게시글이 등록되지 않았다면 "등록된 게시글이 없습니다" 를 출력합니다.

 

7. 게시글의 번호를 이용해 게시글에 댓글 작성하기(게시글 번호)
    - 원하는 게시글에 댓글을 작성할 수 있습니다.
    - 게시글 마다 댓글은 10개까지만 등록할 수 있습니다.
    - 게시글에 이미 10개의 게시글이 등록된 상태라면 "댓글을 더 이상 등록할 수 없습니다."를 출력합니다.
    - 만약, 존재하지 않는 게시글에 댓글을 작성하려는 경우 "잘못된 게시글 번호입니다"가 출력되어야 합니다.

 

8. 게시글에 등록된 댓글 삭제하기(삭제하려는 댓글이 있는 게시글 번호, 삭제하려는 댓글 번호)
    - 원하는 게시글에 등록된 댓글을 삭제할 수 있습니다.
    - 만약, 존재하지 않는 게시글의 댓글을 삭제하려는 경우 "잘못된 게시글 번호입니다"가 출력되어야 합니다.
    - 만약, 존재하지 않는 댓글을 삭제하려는 경우 "잘못된 댓글 번호입니다"가 출력되어야 합니다.

 

9. 게시글에 등록된 댓글 하나 추천하기(추천하려는 댓글이 있는 게시글 번호, 추천하려는 댓글 번호)
    - 원하는 게시글에 등록된 댓글을 추천할 수 있습니다.
    - 추천된 댓글은 댓글 추천 수가 하나 증가합니다.
    - 만약, 존재하지 않는 게시글의 댓글을 추천하려는 경우 "잘못된 게시글 번호입니다"가 출력되어야 합니다.
    - 만약, 존재하지 않는 댓글을 추천하려는 경우 "잘못된 댓글 번호입니다"가 출력되어야 합니다.

 

10. 게시글 제목으로 검색하기(검색어)
    - 검색어를 입력해 게시글 제목에 검색어가 포함되어 있는 게시글의 목록을 출력합니다.
    - 검색된 결과가 없을 경우 "검색된 게시글이 없습니다."를 출력합니다.

 

11. 게시글 목록 전체 삭제하기()
    - 게시글 목록을 제거합니다.
    - 게시글이 하나도 없을 경우 "제거할 게시글이 없습니다"를 출력합니다.
    - 제거가 완료되면 "n개의 게시글을 삭제했습니다"를 출력합니다.

 

12. 원하는 게시글의 모든 댓글 삭제하기.(게시글 번호)
    - 게시글의 번호를 이용해, 해당 게시글의 댓글을 모두 제거합니다.
    - 만약, 존재하지 않는 게시글의 모든 댓글을 삭제하려는 경우 "잘못된 게시글 번호입니다"가 출력되어야 합니다.
    - 제거가 완료되면 "n개의 댓글을 삭제했습니다"를 출력합니다.
    - 만약, 제거할 댓글이 없다면 "등록된 댓글이 없습니다"를 출력합니다.
